# 📚 Módulo 6: Interpret GitHub Actions Workflow

## 🎯 Objetivo del Módulo

Aprender a leer, entender e interpretar workflows de GitHub Actions existentes.

## 📖 Contenido

### 6.1 Anatomía de un Workflow

#### Leer un workflow paso a paso:
1. **Name**: Propósito del workflow
2. **On**: Eventos que lo disparan
3. **Jobs**: Tareas principales
4. **Steps**: Acciones específicas
5. **Context**: Variables disponibles

### 6.2 Logs y Debugging

#### Entender los logs:
- ✅ **Verde**: Paso exitoso
- ❌ **Rojo**: Error
- **Tiempo**: Duración de ejecución
- **Output**: Información detallada
